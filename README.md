# Карта изучения православия

Интерактивная карта-«древо» для самостоятельного изучения православия: темы от основ веры до святых отцов,
у каждой — книги, лекции и видео, с пометкой «с чего начать». Дерево растёт снизу вверх: внизу корни (основы),
выше — средний и углублённый уровни; разделы идут колонками слева направо.

Сайт: https://edgeel.github.io/orthodox-map/

Это статический сайт: генератор `omap` (Rust) читает папку `content/`, проверяет её и собирает `dist/`, который
публикует GitHub Pages. Без внешних CDN, шрифтов и трекеров; работает офлайн (PWA), светлая и тёмная тема.
Весь сайт можно выгрузить одним HTML-файлом и отправить знакомым.

## Как собрать и посмотреть

Нужны Rust (`rustup`, stable) и [just](https://just.systems).

```sh
just serve            # собрать и открыть на http://127.0.0.1:8000/ (после правок перезапустить)
just check            # только проверить содержание
just build            # собрать сайт в dist/ (вместе с dist/orthodox-map.html)
just single           # только один файл: dist/orthodox-map.html
just test lint        # тесты (Rust + JS в QuickJS), формат и clippy
```

Другая папка с содержанием: `just serve ../orthodox-map-content` (или `omap build --content ПАПКА --out ПАПКА`).
Для `just test` и `just single` нужен [uv](https://docs.astral.sh/uv/): JavaScript проверяется в QuickJS
(`tools/jscheck.py`), без браузера.

## Сайт для читателя

- **Карта** открывается сразу, и на компьютере, и на телефоне; **список** — переключателем рядом с поиском
  (выбор запоминается). Внизу корни и 🌱 начальные темы; стартовый масштаб показывает их целиком.
- **Телефон** (уже 700 px): шапка в одну строку (поиск, кнопка фильтров, карта/список, меню); уровни, тип
  материала, отметки и пути — за кнопкой фильтров (точка на ней — фильтр включён). Карта двигается пальцем,
  масштаб — щипком. Карточка темы выезжает снизу шторкой; закрыть — ✕ или потянуть за полоску вниз.
- **Отметки** на карточке темы: 🔖 «хочу изучить», 📖 «читаю», ✓ «изучил». На карте: пунктирная рамка, кольцо,
  закрашенный кружок; в списке — значок. Фильтр «Мои отметки» оставляет на карте и в списке только темы
  с выбранной отметкой (или без отметок). Хранятся в этом браузере (`localStorage`, ключ `omap.progress.v1`);
  в меню ⋯ — сохранить в JSON и загрузить обратно (старые файлы читаются как раньше).

## Один HTML-файл

`just single` (или `omap build --single dist/orthodox-map.html`) собирает весь сайт в один файл: содержание,
стили, скрипт и иконка внутри. В нём карта и карточки, список, поиск, фильтры, пути и отметки; переходы на
темы — внутри файла (`#topic/<id>`). Открывается двойным щелчком (`file://`), без сети и без service worker;
наружу ведут только ссылки на материалы и «🔗 Ссылка на тему» (на сайт из `site.toml`). Страниц путей в файле
нет — путь подсвечивается на карте. `just build` кладёт такой же файл в `dist/orthodox-map.html`, а на сайте
он скачивается из меню ⋯ («Скачать карту одним файлом»). `omap build` очищает `dist/`, поэтому `--single` в
`dist/` — после сборки сайта.

## Как устроено содержание

```
content/
  sections.toml        разделы: id, название, порядок, цвет, иконка, описание
  routes.toml          готовые маршруты: id, название, описание, список тем по порядку
  topics/<раздел>/<id>.md   одна тема — один файл
site.toml              название сайта, адрес (base_url), подписи — не часть content/
```

### Как добавить тему

1. Создайте файл `content/topics/<раздел>/<id>.md`. Папка — это `id` раздела из `sections.toml`, имя файла —
   `id` темы (латиница, цифры, дефис).
2. Вверху — шапка YAML между строками `---`, ниже — текст темы в Markdown.
3. `just check` покажет ошибки с именем файла и подсказкой, `just serve` — как это выглядит.

Пример:

```markdown
---
id: "simvol-very"
title: "Символ веры"
section: "osnovy"
level: 1
needs: ["o-chem-pravoslavie"]
order: 4
summary: "Двенадцать строк, в которых сжата вся вера Церкви."
time: "≈ 1 ч"
tags: ["символ веры", "катехизис"]
materials:
  - title: "Почему Символ веры так важен"
    author: "прот. Андрей Ткачёв"
    type: "video"
    url: "https://www.youtube.com/watch?v=XXXXXXXXXXX"
    lang: "ru"
    time: "18 мин"
    start: true
    note: "Короткое живое объяснение; лучше всего для первого знакомства."
  - title: "Пространный христианский катехизис"
    author: "свт. Филарет (Дроздов)"
    type: "book"
    url: "https://azbyka.ru/otechnik/Filaret_Moskovskij/prostrannyj-pravoslavnyj-katekhizis/"
    lang: "ru"
    time: "≈ 150 стр."
---

Символ веры — это … (несколько строк простым языком: о чём тема и к чему ведёт).

## Проверь себя

- Какие члены Символа говорят о Сыне?

## Дальше

- [Катехизис](katehizis)
```

Поля шапки:

- `level` — 1 начальный (внизу дерева), 2 средний, 3 углублённый.
- `needs` — на каких темах строится эта (рисуются стрелками). Циклы и несуществующие темы — ошибка.
- `order` — порядок внутри раздела и уровня.
- `materials[].type` — `video`, `playlist`, `book`, `article`, `course`, `audio`; `lang` — `ru` или `en`;
  `start: true` — «с чего начать» (1–2 на тему); `alt_url` — то же самое в другом месте (необязательно).
- Строки лучше брать в двойные кавычки: двоеточие внутри строки без кавычек ломает YAML.
- Ссылка на другую тему в тексте: `[текст](id-темы)` или `[[id-темы]]`; внешние — только `https://`.

## Как опубликовать

Один раз: `just publish` — создаёт публичный репозиторий `edgeel/orthodox-map`, пушит его и включает GitHub
Pages (сборка через GitHub Actions). Дальше каждый push в `main` собирает и выкладывает сайт сам
(`.github/workflows/pages.yml`); `just deploy` проверяет всё и пушит. Ход сборки: `gh run list`.

## Для разработчиков

`AGENTS.md` — устройство кода и правила, `FEATURES.md` — что сделано и что в планах, `CHANGELOG.md` — изменения.
